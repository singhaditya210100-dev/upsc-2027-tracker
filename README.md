# UPSC 2027 Mock Tracker

A single-page study tracker for the UPSC 2027 Prelims and Mains plan.

- **Current focus**: this week's GS and Management optional focus, today's study block and the next syllabus topics to study.
- **Alerts**: upcoming, overdue and unreviewed mock tests, portion gaps before a test, and falling behind the timetable.
- **Portion coverage**: 911 micro-topics across 19 subjects (including the Management optional, Papers I and II), marked Not Started → P1 Read → P2 Revised → P3 Confident.
- **Mock tests**: 37 planned tests mapped to VisionIAS test series, with score logging and a score trace.

Everything runs in the browser from `index.html`. Progress is saved in the browser's local storage only, so use **Export backup** / **Import backup** at the bottom of the page to keep a copy or move to another device.
